Twin Reef is a spot-the-difference game across six hand-drawn coral-reef scenes: find 8 hidden differences between two near-identical reef pictures in each scene, with a magnifier lens, full keyboard play, hints, a countdown clock and a time bonus.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and dive in. Click a difference, or steer with the arrow keys and press Enter. H shows a hint, M toggles the magnifier, P pauses, R retries a scene.
